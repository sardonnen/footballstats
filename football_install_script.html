⚽ Installation Football Stats

Assistant d'installation pour la version modulaire

📁 Étape 1 : Structure des fichiers

Votre application doit être organisée comme suit :

football-stats/ ├── index.html ├── styles/ │ ├── base.css │ ├── mobile.css │ └── live.css ├── js/ │ ├── config.js │ ├── utils.js │ ├── storage.js │ ├── navigation.js │ ├── match.js │ ├── live.js │ ├── mobile.js │ └── app.js └── README.md

💾 Étape 2 : Téléchargement automatique

Cliquez sur le bouton ci-dessous pour télécharger tous les fichiers automatiquement :

🛠️ Étape 3 : Installation manuelle (alternative)

Si le téléchargement automatique ne fonctionne pas :

  1. Créez un dossier football-stats
  2. Créez les sous-dossiers styles et js
  3. Copiez chaque fichier depuis Claude dans le bon dossier
  4. Respectez exactement la structure ci-dessus

⚠️ Instructions importantes

  • Ordre d'installation : Créez d'abord la structure de dossiers
  • Noms de fichiers : Respectez exactement la casse (majuscules/minuscules)
  • Encodage : Sauvegardez tous les fichiers en UTF-8
  • Extensions : .html pour index, .css pour styles, .js pour scripts

🚀 Étape 4 : Lancement

Une fois tous les fichiers en place :

  1. Ouvrez le fichier index.html dans votre navigateur
  2. L'application devrait se charger automatiquement
  3. Si il y a des erreurs, vérifiez la console (F12)

📱 Étape 5 : Installation mobile

Android : Chrome → Menu → "Ajouter à l'écran d'accueil"

iOS : Safari → Partager → "Sur l'écran d'accueil"

🆘 Besoin d'aide ?

Si vous rencontrez des problèmes :

  • Vérifiez que JavaScript est activé
  • Contrôlez la console (F12) pour les erreurs
  • Assurez-vous que tous les fichiers sont présents
  • Testez avec un navigateur récent (Chrome, Firefox, Safari)
